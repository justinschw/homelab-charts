1. Before installing: create the Cloudflare API key secret in the `cert-manager` namespace.

   Replace `YOUR_CLOUDFLARE_API_KEY` with your Global API Key (or use a token and adapt values.yaml).

   kubectl -n cert-manager create secret generic cloudflare-api-key --from-literal=api-key='YOUR_CLOUDFLARE_API_KEY'

2. Install the chart (example installs Certificate into the namespace set in `values.yaml`):

   helm upgrade --install app-ingress . -n cert-manager --create-namespace

3. Verify:

   kubectl get clusterissuer {{ .Values.issuer.name }}
   kubectl -n {{ .Values.certificate.namespace }} get certificate {{ .Values.certificate.name }}
   kubectl -n {{ .Values.certificate.namespace }} get secret {{ .Values.certificate.secretName }}

Notes:
- This chart creates a `ClusterIssuer` that references the Cloudflare API key stored in the `cert-manager` namespace.
- Ensure `cert-manager` is installed and running in the `cert-manager` namespace before applying.
